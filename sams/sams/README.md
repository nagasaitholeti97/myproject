# SAMS - Student Attendance Management System

Front-end demo with student and faculty portals.

## Run
Open `index.html` in a browser. No build step or server is needed.

## Files
- index.html : page structure
- css/styles.css : all styles (light and dark themes)
- js/app.js : sample data, sign-in, student and faculty screens

Data is held in memory and resets on reload. To store it permanently, connect the
screens to the Spring Boot REST API and PostgreSQL schema from the architecture and ER diagrams.
